1. **`generate_instant_business_website`** — Generates a live, interactive Next.js business website preview URL (`https://www.paladinfront.com/web-factory/preview/...`) from a business name, industry, location, custom headline, services, and brand color in under 2 seconds.

3. **`check_business_domain_and_launch_plan`** — Recommends available domain naming patterns and returns direct `$0 Setup + $29/mo` and `$199 VIP Done-For-You` launch links.
4. **`get_easiest_website_builder_guide`** — Compares total cost of ownership, speed, and SEO/AEO performance against Wix, Squarespace, WordPress, and $10,000 agencies.
